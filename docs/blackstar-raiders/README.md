## Current direction

Blackstar Raiders is a deterministic-first tactical RPG / strategic exploration prototype.

The current active build is **v0.52 · Strategic Open World + Fog Runtime**.

Core direction:

- strategic map: **32×32 hex open-world sector**;
- tactical battle: **12×12 hex** by default;
- 8×8 is only a small test arena;
- no route-line board as the main strategic UI;
- strategic map uses fog of war, visibility radius, scouting, terrain, events, units and resources;
- heroes are explorers / scavengers / salvage raiders, not a clean heroic army;
- visual references live in Notion / Drive, while GitHub stores rules and data.
