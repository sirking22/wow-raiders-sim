# Hex Field Standard v0.40

Поле не должно выглядеть как сломанный клин. Для UI фиксируем: **прямоугольная тактическая арена на гексах**.

## Стандарты

1. `STANDARD_TACTICAL_FIELD` — обычный бой, `11×9`.
2. `BOSS_ARENA` — босс/ритуал, `13×11`, края можно затемнять как стены/пропасти.
3. `CORRIDOR_CHOKEPOINT` — коридор/засада, `12×7`, боковые клетки затемнены.

## Правило

Препятствия и недоступные зоны — затемнённые hex-тайлы, не дырки в сетке.
